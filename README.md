# Store Sales Dashboard – Looker Studio

## Project Overview
This project presents an interactive **Store Sales Dashboard** built using **Google Looker Studio** to analyze sales performance across different dimensions such as region, category, segment, shipping mode, and payment method.

The dashboard helps in identifying sales trends, top-performing states, and customer segments, enabling better business insights and decision-making.

---

## Objectives
- Analyze overall sales, profit, and quantity.
- Understand sales distribution by:
  - Region
  - Category
  - Segment
  - Payment Mode
  - Shipping Mode
  - State
- Provide an interactive dashboard for quick insights.

---

## Tools & Technologies
- Google Looker Studio  
- Google Sheets / CSV (Data Source)  
- Data Cleaning and Preparation  

---

## Dashboard Features
- KPI cards displaying:
  - Total Sales
  - Total Profit
  - Total Quantity
- Interactive filter:
  - Region filter for dynamic analysis
- Visualizations:
  - Sales by Category
  - Sales by Ship Mode
  - Sales by State
  - Region-wise Sales Distribution
  - Segment-wise Sales Distribution
  - Payment Mode Analysis
  - Geographic Sales Map

---

## Key Insights
- Standard Class shipping contributes the highest share of sales.
- Consumer segment accounts for the largest portion of total revenue.
- California is the top-performing state in sales.
- Office Supplies category generates the highest sales among product categories.
